# INSHLT Learning - Heart & Lung Transplantation Education

Industry-led certification programs with live expert sessions, clinical insights, assessments, and recognized certification from INSHLT India.

## Features

- **Neurology Care**: Leading expert neurology care with customized treatment plans.
- **Transplant Education**: Specialized transplant education center for heart and lung transplantation.
- **Interactive Courses**: Advanced courses for healthcare professionals.
- **FAQ Section**: Comprehensive answers to common neurological and transplant questions.

## Tech Stack

- **Framework**: React with Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Run dev server: `npm run dev`
